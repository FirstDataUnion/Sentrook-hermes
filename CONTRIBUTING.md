# Contributing

**This repo does not accept contributions.**

1. Open issues and pull requests against
   [FirstDataUnion/Sentrook](https://github.com/FirstDataUnion/Sentrook).
2. Develop under `integrations/hermes/plugin/` in that monorepo.
3. Maintainers promote a release with the gated
   `release-hermes-plugin` workflow in Sentrook, which updates this mirror.

Manual pushes to this repository are out of process and may be force-replaced
by the next CI promote.
